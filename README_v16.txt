MARYLIN.DATA — v16

Nuevo: navegador histórico de estados dentro de la sección ESTADO ACTUAL.
Permite desplazar una barra desde MD_0001 hasta el estado actual y seleccionar cada estado.
La interfaz cambia el identificador, fecha, estado y la imagen fragmento asociada.

IMPORTANTE:
El archivo público actual contiene los metadatos de 22 estados, pero el repositorio publicado actualmente no contiene los PNG históricos MD_0001.png ... MD_0021.png. La interfaz queda preparada para mostrarlos cuando esos archivos se publiquen junto al sitio. Mientras tanto, al seleccionar uno que no tenga imagen publicada se muestra un aviso de "Fragmento histórico pendiente de publicación" en lugar de una imagen rota.

Para publicar:
- reemplazar index.html
- reemplazar style.css
- agregar/reemplazar app.js
- conservar los JSON e imágenes actuales
