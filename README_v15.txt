MARYLIN.DATA v15 — ajuste de lectura

CAMBIO:
La página conserva el sistema visual y los datos actuales, pero mejora la entrada conceptual:
- Pregunta filosófica al inicio.
- Explicación humana antes de entrar en las métricas.
- Frase clave: “No se trata de medir quién soy, sino de observar cómo voy cambiando.”
- Se aclara que la experiencia la traduce manualmente la autora y el algoritmo aplica reglas.
- Se mantiene la aclaración de que los elementos visuales no representan emociones directamente.
